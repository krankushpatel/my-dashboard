# AI Engineering Portfolio

Practical work across the AI engineering stack, from model fundamentals to production systems.

## Focus

**Python → ML → Deep Learning → PyTorch → Computer Vision → LLMs → RAG → Fine-tuning → Evaluation → Inference → Deployment**

## Project Standard

A serious AI project should document:

1. Problem and motivation
2. Data / dataset
3. Baseline
4. Model and architecture
5. Training / experiment setup
6. Evaluation metrics
7. Failure analysis
8. Inference path
9. Deployment
10. Limitations and next improvements

## Engineering Priorities

- Reproducibility over one-off demos
- Evaluation over intuition
- Failure analysis over cherry-picked examples
- Simple baselines before complex models
- Production constraints considered early
