# Production & Startup Work

Projects that move from **idea → validated problem → working product → real usage**.

## Build Loop

**Problem → Validate → MVP → Ship → Measure → Iterate → Production → Revenue**

## What Belongs Here

- Deployed applications
- Real user-facing products
- AI automation
- Startup MVPs
- Developer tools
- Projects with measurable outcomes

## Project Evidence

Each project should make it easy to understand:

- Who has the problem
- What was built
- Why the architecture was chosen
- What users did with it
- What was measured
- What failed
- What changed
- What happens next
